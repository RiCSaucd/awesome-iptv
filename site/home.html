Use this in the house

Run the stack on one always-on computer (or a Raspberry Pi / NAS). Phones, tablets, and TVs on the same Wi-Fi open the catalog and Watch page. Stremio on this computer can install the addon over localhost.

  1. 1. Start the stack

    On this computer, from the repo:

    npm run home

    Or with Docker:

    docker compose up --build

  2. 2. Open the catalog on any device

    Use one of these URLs on a phone or TV browser:

    • 3. Watch live TV in the browser

      Same devices, no extra app: Watch. That page reads the playlist this box is serving (default is a tiny test list; point IPTV_PLAYLIST_URL at your own .m3u for real channels).
